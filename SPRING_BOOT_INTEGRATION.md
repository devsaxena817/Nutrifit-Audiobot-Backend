# NutriFit AI Backend Integration Guide

This file explains what this Python backend does, what API endpoints it provides, and how a Spring Boot project can use it.

## 1. What This Backend Does

This project is a Flask API backend for NutriFit AI.

It accepts an audio file of a dietician-client consultation, sends that audio to Gemini, and returns:

- full transcript of the audio
- short consultation summary
- key health concerns
- dietary habits
- allergies or restrictions
- suggested nutrition improvements
- personalized nutrition details
- tone or emotion analysis
- follow-up questions
- optional PDF report as base64

This backend does not have a frontend page. It is meant to be called by another backend, such as Spring Boot.

Recommended flow:

```text
Frontend
  -> Spring Boot backend
  -> Python NutriFit AI backend on Render
  -> Gemini API
```

The frontend should call Spring Boot. Spring Boot should call this Python API internally.

## 2. Render Deployment Setup

Deploy this Python project as a Web Service on Render.

Use this start command:

```bash
gunicorn app:app
```

Set these environment variables in Render:

```env
GOOGLE_API_KEY=your_gemini_api_key
SERVICE_API_TOKEN=your_secret_token_shared_with_spring_boot
MAX_UPLOAD_MB=25
```

`GOOGLE_API_KEY` is your Gemini API key.

`SERVICE_API_TOKEN` is a secret token that you create yourself. Spring Boot must send this token when calling the Python API.

Generate a token locally with:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

After deployment, your base URL will look like:

```text
https://your-service-name.onrender.com
```

## 3. API Endpoints

### `GET /`

Basic service information.

Example:

```text
GET https://your-service-name.onrender.com/
```

Returns:

```json
{
  "service": "nutrifit-ai",
  "message": "NutriFit AI microservice is running. Use /health, /models, or POST /analyze.",
  "endpoints": {
    "health": "/health",
    "models": "/models",
    "analyze": "/analyze"
  }
}
```

### `GET /health`

Checks if the Python backend is running.

Example:

```text
GET https://your-service-name.onrender.com/health
```

Returns:

```json
{
  "status": "ok",
  "service": "nutrifit-ai",
  "model_name": "models/gemini-1.5-flash"
}
```

### `GET /models`

Lists Gemini models available for the configured API key.

Example:

```text
GET https://your-service-name.onrender.com/models
```

Returns:

```json
{
  "model_name": "models/gemini-1.5-flash",
  "available_models": []
}
```

### `POST /analyze`

This is the main endpoint.

It accepts an audio file, analyzes it with Gemini, and returns AI-generated nutrition analysis.

Request type:

```text
multipart/form-data
```

Required form field:

```text
audio = audio file
```

Optional form field:

```text
include_pdf = true
```

Required header when `SERVICE_API_TOKEN` is set:

```http
Authorization: Bearer your_secret_token
```

Example using curl:

```bash
curl -X POST https://your-service-name.onrender.com/analyze \
  -H "Authorization: Bearer your_secret_token" \
  -F "audio=@sample.mp3" \
  -F "include_pdf=true"
```

Supported audio types:

- MP3
- WAV
- M4A / MP4 audio
- WEBM
- OGG

## 5. Spring Boot Configuration

Add these values in `application.properties`:

```properties
ai.python.base-url=https://your-service-name.onrender.com
ai.python.service-token=your_secret_token
```

Do not put `ai.python.service-token` in frontend code.

The token should stay only inside Spring Boot server configuration.

## 6. Spring Boot DTO

Create a DTO for the Python API response.

```java
package com.example.nutrifit.dto;

import java.util.Map;

public class AiAnalysisResponse {
    private Map<String, Object> json;
    private String report_text;
    private String model_name;
    private String pdf_base64;
    private String pdf_filename;
    private String pdf_error;

    public Map<String, Object> getJson() {
        return json;
    }

    public void setJson(Map<String, Object> json) {
        this.json = json;
    }

    public String getReport_text() {
        return report_text;
    }

    public void setReport_text(String report_text) {
        this.report_text = report_text;
    }

    public String getModel_name() {
        return model_name;
    }

    public void setModel_name(String model_name) {
        this.model_name = model_name;
    }

    public String getPdf_base64() {
        return pdf_base64;
    }

    public void setPdf_base64(String pdf_base64) {
        this.pdf_base64 = pdf_base64;
    }

    public String getPdf_filename() {
        return pdf_filename;
    }

    public void setPdf_filename(String pdf_filename) {
        this.pdf_filename = pdf_filename;
    }

    public String getPdf_error() {
        return pdf_error;
    }

    public void setPdf_error(String pdf_error) {
        this.pdf_error = pdf_error;
    }
}
```

## 8. Spring Boot Service

This service receives an uploaded audio file from Spring Boot and forwards it to the deployed Python backend.

```java
package com.example.nutrifit.service;

import com.example.nutrifit.dto.AiAnalysisResponse;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.ByteArrayResource;
import org.springframework.http.HttpEntity;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.stereotype.Service;
import org.springframework.util.LinkedMultiValueMap;
import org.springframework.util.MultiValueMap;
import org.springframework.web.client.RestTemplate;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;

@Service
public class AiAnalysisService {

    private final RestTemplate restTemplate;

    @Value("${ai.python.base-url}")
    private String pythonBaseUrl;

    @Value("${ai.python.service-token}")
    private String serviceToken;

    public AiAnalysisService(RestTemplate restTemplate) {
        this.restTemplate = restTemplate;
    }

    public AiAnalysisResponse analyzeAudio(MultipartFile audio, boolean includePdf) {
        try {
            ByteArrayResource fileResource = new ByteArrayResource(audio.getBytes()) {
                @Override
                public String getFilename() {
                    return audio.getOriginalFilename();
                }
            };

            HttpHeaders fileHeaders = new HttpHeaders();
            String contentType = audio.getContentType() != null
                    ? audio.getContentType()
                    : "audio/mpeg";
            fileHeaders.setContentType(MediaType.parseMediaType(contentType));

            HttpEntity<ByteArrayResource> fileEntity =
                    new HttpEntity<>(fileResource, fileHeaders);

            MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
            body.add("audio", fileEntity);
            body.add("include_pdf", String.valueOf(includePdf));

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.MULTIPART_FORM_DATA);
            headers.setBearerAuth(serviceToken);

            HttpEntity<MultiValueMap<String, Object>> requestEntity =
                    new HttpEntity<>(body, headers);

            ResponseEntity<AiAnalysisResponse> response = restTemplate.exchange(
                    pythonBaseUrl + "/analyze",
                    HttpMethod.POST,
                    requestEntity,
                    AiAnalysisResponse.class
            );

            return response.getBody();
        } catch (IOException e) {
            throw new RuntimeException("Failed to read uploaded audio", e);
        }
    }
}
```

## 9. Spring Boot Controller

This exposes an endpoint for the frontend.

The frontend should call this Spring Boot endpoint, not the Python backend directly.

```java
package com.example.nutrifit.controller;

import com.example.nutrifit.dto.AiAnalysisResponse;
import com.example.nutrifit.service.AiAnalysisService;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
@RequestMapping("/api/ai")
public class AiAnalysisController {

    private final AiAnalysisService aiAnalysisService;

    public AiAnalysisController(AiAnalysisService aiAnalysisService) {
        this.aiAnalysisService = aiAnalysisService;
    }

    @PostMapping("/analyze")
    public ResponseEntity<AiAnalysisResponse> analyze(
            @RequestParam("audio") MultipartFile audio,
            @RequestParam(value = "includePdf", defaultValue = "false") boolean includePdf
    ) {
        AiAnalysisResponse response = aiAnalysisService.analyzeAudio(audio, includePdf);
        return ResponseEntity.ok(response);
    }
}
```

## 10. Frontend Usage

The frontend should upload audio to Spring Boot:

```text
POST /api/ai/analyze
```

Form data:

```text
audio = selected audio file
includePdf = true or false
```

Spring Boot will then call:

```text
POST https://your-service-name.onrender.com/analyze
```

Field mapping:

| Frontend to Spring Boot | Spring Boot to Python |
| --- | --- |
| `audio` | `audio` |
| `includePdf` | `include_pdf` |

## 11. Using The PDF Output

If `includePdf=true`, the Python backend returns:

```json
{
  "pdf_base64": "JVBERi0x...",
  "pdf_filename": "NutriFit_Report.pdf"
}
```

Spring Boot can return this directly to the frontend.

If Spring Boot needs to decode and save the PDF:

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Base64;

byte[] pdfBytes = Base64.getDecoder().decode(response.getPdf_base64());
Files.write(Path.of(response.getPdf_filename()), pdfBytes);
```

## 12. Common Errors

### `401 Unauthorized`

The Spring Boot request is missing the token or using the wrong token.

Check:

```java
headers.setBearerAuth(serviceToken);
```

Also check that the Spring Boot token matches the `SERVICE_API_TOKEN` value in Render.

### `415 Unsupported audio type`

The uploaded file type is not supported.

Use MP3, WAV, M4A, WEBM, or OGG.

### `500 Model call failed`

The Python backend reached Gemini but Gemini failed.

Common reasons:

- wrong `GOOGLE_API_KEY`
- Gemini quota issue
- unsupported audio content
- temporary Gemini API failure

### Spring Boot cannot reach Python

Check:

- Render service is deployed and running
- `ai.python.base-url` is correct
- `/health` works in browser or Postman
- Spring Boot server has internet access

## 13. Quick Handoff Summary

Give your Spring Boot teammate these values:

```text
Python base URL:
https://your-service-name.onrender.com

Analyze endpoint:
POST /analyze

Auth header:
Authorization: Bearer your_secret_token

Required form-data:
audio = audio file

Optional form-data:
include_pdf = true
```

Spring Boot should expose its own endpoint, for example:

```text
POST /api/ai/analyze
```

The frontend calls Spring Boot, Spring Boot calls this Python backend, and this Python backend returns the AI nutrition analysis.
